## Introduction

TFItPiCAN is a comprehensive software solution for interfacing with and simulating CAN Bus operations on both Mac and Raspberry Pi platforms. It supports both hardware and virtual CAN interfaces, simulation scenarios, and provides a user-friendly graphical interface for monitoring and control.

### Purpose

The primary goals of TFItPiCAN are:
- Provide a flexible interface for CAN bus communication.
- Support both hardware and virtual CAN interfaces.
- Enable simulation of various automotive scenarios.
- Offer a user-friendly GUI for control and monitoring.
- Ensure cross-platform compatibility (Mac development, Raspberry Pi deployment).
